# Uliana Khmel — Personal Website

This repository contains the source code for the personal website of Uliana Khmel, a Business Operations & Project Management professional, currently serving as COO & Customer Experience Lead at DreamProIT.

🌐 Live Site: [https://ulianakhmel.github.io](https://ulianakhmel.github.io/)

## 📌 Overview

The website highlights professional experience, core skills and tools, speaking engagements and industry events, education, as well as selected publications and features.

## 🛠️ Repository Structure

* `index.html` — Main website markup, styles, and interactive components (self-contained, no build step).
* `assets/` — Profile photo and institution/organization logos.

## 🚀 Local Development

Since this is a static site hosted on GitHub Pages, no build process is required. You can serve the site locally using any static HTTP server:

```
python3 -m http.server 8000
```

Then navigate to `http://localhost:8000` in your web browser.
